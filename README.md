## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS v4 · Motion · `next/font` · `next/image`

## Boas práticas

- Conteúdo (contatos, projetos, pacotes, FAQ) centralizado em `src/content/site.ts`
- Capas dos projetos são capturas reais dos sites publicados (`public/projects`)
- Acordeão de dúvidas com `<details>` nativo — acessível e sem JavaScript
- Animações respeitam "reduzir movimento"; HTML semântico e foco visível

## Rodando localmente

```bash
npm install
npm run dev
```
